## 🎯 配置概览

### 分辨率和帧率
- **分辨率**: 640×480 (VGA标准)
- **目标帧率**: 18fps
- **像素总数**: 307,200 pixels
- **帧大小**: 900KB
- **数据量**: 是480×320的2倍，是320×240的4倍

### 时序参数
```
PCLK: 56MHz
TOTAL_H_PIXEL: 1856 (640 + 1216)
TOTAL_V_PIXEL: 1676 (480 + 1196)
实际帧率: 18.00 fps
帧间隔: 55.56ms
```

### SDRAM配置
- **时钟频率**: 125MHz
- **突发长度**: 4 words
- **地址范围**: 0 ~ 307199 (0x4AFFF)

### 优化参数
- **UDP流控阈值**: 3950 words (96.6%满)
- **读取延迟**: 5000周期 (40μs @ 125MHz)

================================================================================
性能分析
================================================================================

### 处理时间详细计算

#### 1. SDRAM写入时间
```
像素数量: 307,200
SDRAM时钟: 125MHz (burst-4)
有效写速率: 125MHz / 4 = 31.25MHz
写入时间: 307,200 / 31.25MHz = 9.83ms
```

#### 2. 读取延迟
```
延迟周期: 5000 @ 125MHz
延迟时间: 5000 / 125MHz = 40μs = 0.04ms
```

#### 3. SDRAM读取时间
```
理论读取: 307,200 / 31.25MHz = 9.83ms
UDP流控影响: × 2.1倍（优化后）
实际读取时间: ~20.6ms
```

#### 4. 总处理时间
```
总处理 = 写入 + 延迟 + 读取
      = 9.83ms + 0.04ms + 20.6ms
      = 30.47ms
```

### 安全系数评估

```
帧间隔: 55.56ms
处理时间: 30.47ms
安全系数: 55.56 / 30.47 = 1.82x ✅

安全余量: 55.56ms - 30.47ms = 25.09ms
```

**评估结果**: ⭐⭐⭐⭐ **推荐配置**
- 安全系数1.82x属于良好范围
- 25ms余量可应对性能波动
- 稳定可靠，适合生产环境

================================================================================
网络带宽分析
================================================================================

### UDP传输参数
```
UDP包大小: 1440 bytes (480 words × 3)
UDP包数/帧: 900KB / 1440B = 642 packets
UDP包数/秒: 642 × 18fps = 11,556 packets/s
```

### 数据速率
```
有效数据: 900KB × 18fps = 16,200 KB/s = 15.82 MB/s = 126.6 Mbps

以太网开销计算:
- UDP包: 1440 bytes
- IP头: 20 bytes
- UDP头: 8 bytes
- 以太网头+CRC: 18 bytes
- 总包大小: 1486 bytes

实际网络速率: 1486B × 11,556 pkt/s = 17.17 MB/s = 137.4 Mbps

千兆以太网利用率: 137.4 / 1000 = 13.7% ✅
```

### 与其他配置对比

| 配置 | 分辨率 | 帧率 | 数据速率 | 网络利用率 |
|------|--------|------|----------|-----------|
| 初始 | 640×480 | 0.9fps | 7.7 Mbps | 0.8% |
| 阶段1 | 320×240 | 15fps | 32.4 Mbps | 3.2% |
| 阶段2 | 480×320 | 27fps | 115.9 Mbps | 11.6% |

测试建议
================================================================================

### 第一阶段：基础功能验证

1. **编译检查**
   - 打开Tang Dynasty TD软件
   - 综合工程（检查Error/Warning）
   - 时序分析（确保Timing Met）
   - 资源使用率（应该略微增加）

2. **初步测试**
   - 烧录FPGA
   - 检查是否有图像输出
   - 观察分辨率是否正确（640×480）
   - 运行5-10分钟观察稳定性

### 第二阶段：性能监控

3. **图像质量检查**
   - 无明显撕裂或错位
   - 无噪点或马赛克
   - 颜色准确（RGB888）
   - 边缘清晰

4. **帧率验证**
   - 使用UDP接收端统计帧率
   - 应该稳定在18fps左右
   - 观察是否有丢帧

5. **FIFO监控**（如果有调试接口）
   - UDP FIFO: udp_wrusedw应 < 3950
   - 写FIFO: rdusedw应在合理范围
   - 不应频繁满或空

### 第三阶段：压力测试

6. **场景测试**
   - 静态场景：稳定性测试
   - 动态场景：快速移动物体
   - 复杂场景：高细节内容
   - 光照变化：适应性测试

7. **长时间稳定性**
   - 连续运行30分钟
   - 连续运行2小时
   - 观察是否有间歇性问题
   - 监控FPGA温度

### 第四阶段：网络测试

8. **网络质量**
   - 检查UDP包丢失率
   - 测试不同网络环境
   - 验证长距离传输

================================================================================
问题排查指南
================================================================================

### 如果图像撕裂或错位:
1. 降低帧率到15fps测试
   ```verilog
   localparam [12:0] TOTAL_V_PIXEL = V_CMOS_DISP + 13'd1533;  // 15fps
   ```
2. 检查SDRAM地址范围是否正确（307199）
3. 验证相机配置是否支持640×480

### 如果出现丢帧:
1. 检查UDP接收端缓冲区大小
2. 降低UDP流控阈值到3900
3. 增加网络带宽或减少其他流量

### 如果FIFO溢出:
1. UDP流控阈值降低到3900
2. 检查以太网传输是否正常
3. 验证网卡性能

### 如果系统不稳定:
1. 回退到480×320配置验证硬件
2. 检查电源供应是否充足
3. 验证时序是否满足
