## 配置参数

### 视频参数
- **分辨率**: 480×320
- **目标帧率**: 27fps
- **PCLK**: 56MHz
- **TOTAL_H_PIXEL**: 1696 (480 + 1216)
- **TOTAL_V_PIXEL**: 1223 (320 + 903)

### 计算验证
```
实际帧率 = 56,000,000 / (1696 × 1223)
        = 56,000,000 / 2,074,208
        = 27.00 fps ✅
```

### 时序参数
```
帧间隔 = 1000ms / 27fps = 37.04ms
行时间 = 1/56MHz × 1696 = 30.3μs
帧总时间 = 30.3μs × 1223 = 37.04ms
```

================================================================================
性能分析
================================================================================

### SDRAM处理时间（优化后配置）

#### 写入时间:
```
数据量: 480 × 320 = 153,600 pixels
SDRAM写时钟: 125MHz (burst-4)
有效写速率: 125MHz / 4 = 31.25MHz
写入时间: 153,600 / 31.25MHz = 4.92ms
```

#### 延迟时间:
```
延迟周期: 5000周期 @ 125MHz
延迟时间: 5000 / 125MHz = 40μs
```

#### 读取时间:
```
理论读取: 153,600 / 31.25MHz = 4.92ms
UDP流控影响: ~8-10ms (流控阈值3900)
实际读取时间: ~13ms
```

#### 总处理时间:
```
总处理 = 写入 + 延迟 + 读取
      = 4.92ms + 0.04ms + 13ms
      = 17.96ms ≈ 18ms
```

### 安全系数分析

```
帧间隔: 37.04ms
处理时间: 18ms
安全系数: 37.04ms / 18ms = 2.06x ✅

安全余量: 37.04ms - 18ms = 19.04ms
```

**评估**: 2.06x安全系数属于良好范围
- ✅ > 2.0x: 稳定可靠
- ⚠️ 1.5-2.0x: 可接受，需监控
- ❌ < 1.5x: 风险较高

================================================================================
数据流分析
================================================================================

### 每帧数据量
```
像素数量: 480 × 320 = 153,600 pixels
每像素: 3 bytes (RGB888)
帧大小: 153,600 × 3 = 460,800 bytes = 450KB
```

### 27fps数据速率
```
数据速率: 450KB × 27fps = 12,150 KB/s = 11.86 MB/s = 94.88 Mbps
```

### 网络带宽占用
```
UDP包大小: 1080 bytes (360 words × 3)
UDP包数/帧: 450KB / 1080B = 427 packets
UDP包数/秒: 427 × 27fps = 11,529 packets/s

以太网开销:
- UDP包: 1080 bytes
- IP头: 20 bytes
- UDP头: 8 bytes
- 以太网头: 18 bytes (14 header + 4 CRC)
- 总包大小: 1126 bytes

实际网络速率: 1126B × 11,529 pkt/s = 12.98 MB/s = 103.84 Mbps

千兆以太网利用率: 103.84 / 1000 = 10.4% ✅
```

================================================================================
测试建议
================================================================================

### 第一阶段：基础验证

1. **编译工程**
   - 打开Tang Dynasty TD软件
   - 检查综合报告无Error
   - 检查时序报告无违规（Timing Met）
   - 记录资源使用率

2. **初始测试**
   - 烧录FPGA
   - 观察视频输出是否正常
   - 检查是否有明显撕裂或噪点
   - 运行5分钟观察稳定性

### 第二阶段：性能监控

3. **FIFO状态监控**（如果有调试接口）
   - 写FIFO: wrusedw 应该在合理范围波动
   - UDP FIFO: udp_wrusedw 应该 < 3900
   - 不应频繁满或空

4. **长时间稳定性**
   - 连续运行30分钟
   - 观察是否有间歇性问题
   - 检查图像质量是否恒定

### 第三阶段：边界测试

5. **压力测试**
   - 快速移动物体
   - 复杂场景
   - 光照变化
   - 观察系统响应

6. **温度测试**
   - 记录FPGA温度
   - 确保散热良好

================================================================================
问题排查指南
================================================================================

### 如果出现画面撕裂:
1. 降低帧率到25fps重新测试
2. 检查SDRAM时序是否正确
3. 检查以太网连接是否稳定

### 如果出现丢帧:
1. 检查UDP接收端缓冲区大小
2. 降低UDP流控阈值到3800
3. 检查网络带宽是否充足

### 如果出现噪点:
1. 检查相机时序配置
2. 检查FIFO深度是否足够
3. 验证SDRAM读写对齐

### 如果系统不稳定:
1. 回退到15fps配置验证硬件
2. 逐步提升帧率找到临界点
3. 增加安全余量
