# 2025  FPGA Innovative Design Track
# 2025-Anlogic InfoTech Co., LTD.
This is for 2025 Fpgachina competition and Anlogic racetrack and includes the integration of multi-functional Ethernet control and transmission based on HX4S20, featuring UDP image transmission, CNN digital recognition, lane recognition, Sobel edge detection, Otsu binarization algorithm, automatic segmentation based on color space recognition, and pattern matching for license plate recognition. It also includes a comprehensive host computer debugging and display program developed in Python.
