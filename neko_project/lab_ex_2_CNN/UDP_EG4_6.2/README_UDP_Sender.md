# UDP Image Sender - PyQt5 上位机

一个用于向FPGA发送80x100测试图像的PyQt5图形界面应用程序。

## 功能特性

### 图像生成
- **纯色**: 生成单一颜色的图像
- **水平渐变**: 从颜色1到颜色2的水平渐变
- **垂直渐变**: 从颜色1到颜色2的垂直渐变
- **棋盘格**: 可调节方格大小的棋盘图案
- **水平条纹**: 可调节条纹宽度的水平条纹
- **垂直条纹**: 可调节条纹宽度的垂直条纹
- **RGB彩条**: 标准RGB测试彩条（白、黄、青、绿、品红、红、蓝、黑）

### 网络功能
- UDP协议发送图像数据
- 可配置目标IP地址和端口
- 实时发送进度显示
- 多线程发送，不阻塞界面

### 其他功能
- 实时图像预览（放大显示）
- 颜色选择器
- 保存生成的图像为PNG文件
- 状态日志显示

## 安装依赖

```bash
pip install PyQt5 Pillow numpy
```

## 使用方法

### 1. 启动程序

```bash
python udp_image_sender.py
```

### 2. 配置网络参数

- **目标IP**: 输入FPGA的IP地址（默认: 192.168.240.1）
- **目标端口**: 输入UDP端口号（默认: 1）

### 3. 生成测试图像

1. 从"图案选择"下拉菜单选择图案类型
2. 点击"颜色1"或"颜色2"按钮选择颜色（根据图案类型）
3. 调整"图案大小"（适用于棋盘格和条纹）
4. 点击"生成图像"按钮
5. 在右侧预览区查看生成的图像

### 4. 发送图像

1. 确认网络参数正确
2. 点击"发送图像"按钮
3. 在状态日志中查看发送进度
4. 等待发送完成

### 5. 保存图像

点击"保存图像"按钮，图像将保存为PNG文件，文件名包含时间戳。

## 数据格式

发送的UDP数据包格式：
```
f1 + 地址(4位十六进制) + RGB(6位十六进制)
```

示例：
- `f10000ff0000` - 地址0x0000，颜色红色(0xFF0000)
- `f11f3f00ff00` - 地址0x1F3F，颜色绿色(0x00FF00)

地址范围：
- 80×100 = 8000像素
- 地址范围：0x0000 - 0x1F3F (0-7999)

## 注意事项

1. **网络连接**: 确保PC和FPGA在同一网络中，且IP地址配置正确
2. **发送速度**: 程序会在每个像素之间添加0.1ms延迟，避免网络拥塞
3. **图像尺寸**: 固定为80x100像素，与FPGA端配置一致
4. **颜色格式**: RGB888格式，每个通道8位

## 测试建议

### 基础测试
1. **纯色测试**: 测试红、绿、蓝、白、黑等基本颜色
2. **RGB彩条**: 验证颜色显示是否正确

### 进阶测试
1. **渐变测试**: 验证颜色过渡是否平滑
2. **棋盘格**: 测试不同大小的方格显示
3. **条纹**: 测试水平和垂直条纹

## 故障排除

### 发送失败
- 检查网络连接
- 确认IP地址和端口正确
- 检查防火墙设置

### 图像显示异常
- 确认FPGA端代码已正确配置为80x100
- 检查数据格式是否匹配
- 验证地址计算是否正确

### 程序无法启动
- 确认已安装所有依赖包
- 检查Python版本（建议Python 3.7+）

## 技术细节

### 图像生成
- 使用PIL (Pillow)库生成图像
- 支持RGB888颜色格式
- 实时生成，无需预存图像文件

### UDP发送
- 使用Python socket库
- 多线程发送，避免界面冻结
- 每个像素单独发送一个UDP包

### 界面框架
- PyQt5图形界面
- 响应式布局
- 实时预览和日志更新
