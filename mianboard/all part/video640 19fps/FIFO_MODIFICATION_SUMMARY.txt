视频噪点问题修复 - FIFO替换总结
完成日期: 2025-10-24
====================================================================

【问题描述】
视频传输中出现噪点:
- 白色背景下的白色噪点 (读取未初始化的SDRAM区域 0xFFFFFF)
- 黑色背景下的灰色噪点 (读取时序不稳定/FIFO下溢)

【根本原因】
1. app_wrrd_simple.v 中 SDRAM 读地址控制逻辑有bug
2. fifo_sdr_data_2 使用同步FIFO,不适合跨时钟域传输
3. 缺少完善的流控机制 (almost full/almost empty)

【修复方案】
方案1 (已实施): 使用 Anlogic 官方 Soft_FIFO IP 替换

【技术要点】
====================================================================

1. **异步FIFO的重要性**
   - cam_pclk (摄像头时钟) ≠ clk_50m (系统时钟)
   - 必须使用ASYNC模式和Gray Code同步

2. **Almost Full/Empty的作用**
   - Almost Full (1000/1024): 提前警告,暂停写入SDRAM
   - Almost Empty (24/1024): 防止UDP读空

3. **ERAM vs DRAM**
   - ERAM: 使用EBR (嵌入式块RAM),时序更好
   - DRAM: 使用分布式RAM,资源占用小

4. **深度选择**
   - 1024字 = 1024 × 24bit = 3072 Bytes
   - 足够缓冲2-3个UDP包 (1440 Bytes/包)

【故障排查】
====================================================================

如果综合失败:
  1. 检查 soft_fifo_sdr_data.v 是否在项目中
  2. 检查 UDP_EXAMPLE.al 中 IP 引用是否正确
  3. 查看 Messages 窗口的具体错误信息

如果时序不满足:
  1. 检查 .tcl 约束是否生效
  2. 增加 FIFO 深度到 2048
  3. 放宽 Almost Full/Empty 阈值

如果运行后仍有噪点:
  1. 检查 cam_pclk 频率是否稳定
  2. 使用 ILA 调试 FIFO overflow/underflow 信号
  3. 调整 app_wrrd_simple.v 中的读取控制逻辑 (line 154)
