# UDP以太网+数码管显示工程说明

## 功能概述
本工程基于lab_ex_1以太网工程，新增了按键控制数码管显示的功能：
- 保留原有的UDP以太网发送功能
- 新增K2按键控制数码管显示数字1-9循环

## 新增模块说明

### 1. key_counter.v
按键计数器模块，功能：
- 使用K2键作为计数触发
- 集成按键防抖处理（20ms）
- 维护计数器（1-9循环）
- 检测按键下降沿触发计数

### 2. ax_debounce.v
按键防抖模块（从lab_ex_3复制）

### 3. seg_decoder.v
数码管解码器（从lab_ex_3复制）

### 4. seg_scan.v
数码管扫描模块（从lab_ex_3复制）

## 引脚分配
根据HX4S20开发板FPHA.pdf文档：

### 按键
- KEY1: A2 (复位按键)
- KEY2: B2 (计数按键)

### 数码管段选择 (seg_data[7:0])
- seg_data[0]: C15 (a段)
- seg_data[1]: C16 (b段)
- seg_data[2]: B6  (c段)
- seg_data[3]: A5  (d段)
- seg_data[4]: B5  (e段)
- seg_data[5]: A8  (f段)
- seg_data[6]: A7  (g段)
- seg_data[7]: A6  (dp段)

### 数码管位选择 (seg_sel[5:0])
- seg_sel[0]: F16 (第1个数码管)
- seg_sel[1]: E16 (第2个数码管)
- seg_sel[2]: E12 (第3个数码管)
- seg_sel[3]: E10 (第4个数码管)
- seg_sel[4]: C13 (第5个数码管)
- seg_sel[5]: F10 (第6个数码管)

## 使用方法

### 编译和下载
1. 在Tang Dynasty IDE中打开工程
2. 综合、布局布线
3. 生成bit文件并下载到FPGA

### 操作说明
1. **复位系统**: 按下K1键进行系统复位
2. **数码管计数**: 按下K2键，数码管最右位显示数字递增（1→2→...→9→1）
3. **以太网功能**: 工程保持原有的UDP数据发送功能

## 注意事项
1. **开关设置**: 确保开发板上的SW6开关拨到数码管位置（上拨）
2. **时钟域**: 数码管使用25MHz时钟域，与以太网功能隔离
3. **显示位置**: 当前设置仅在最右侧数码管显示，其他位置熄灭
4. **按键防抖**: 已集成20ms防抖时间，避免按键抖动干扰

## 工程特点
- 保持原有UDP以太网发送功能不变
- 新增功能模块化设计，便于维护
- 使用标准的数码管扫描显示方式
- 按键处理包含完整的防抖机制

## 调试建议
1. 如果数码管不显示，检查SW6开关位置
2. 如果按键无响应，检查KEY2引脚连接
3. 可通过LED观察系统运行状态
4. 使用逻辑分析仪监测seg_sel和seg_data信号
