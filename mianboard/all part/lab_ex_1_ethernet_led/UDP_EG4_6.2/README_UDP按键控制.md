# UDP以太网按键控制工程说明

## 功能概述
本工程基于lab_ex_1以太网工程，实现通过以太网发送按键状态来控制远程设备：
- **控制端（本板）**: 检测K2按键，通过UDP发送控制指令到远程设备
- **被控端（远程）**: 接收UDP数据包，控制数码管显示相应数字

## 工作原理

### 数据流程
1. 按下K2按键 → 触发计数器（1-9循环）
2. 计数器变化 → 触发UDP数据发送
3. UDP数据包 → 通过以太网发送到远程设备 (192.168.240.1:1)
4. 远程设备接收 → 解析数据包中的数字值 → 控制数码管显示

### UDP数据包格式
```
字节0-1:  0xF0AA  (帧头标识)
字节2-3:  0x5555  (固定标识)  
字节4-5:  0x1234  (数据类型)
字节6-7:  0x0008  (数据长度8字节)
字节8:    数字值   (1-9)
字节9-15: 0x00    (保留字节)
```

## 新增/修改模块

### 1. key_counter.v (修改)
- 增加 `digit_changed` 输出信号
- 检测按键变化时产生一个时钟周期的脉冲信号
- 触发UDP数据发送

### 2. udp_key_data_tpg.v (新增)
- 替代原有的 `udp_data_tpg.v`
- 基于状态机的UDP数据生成器
- 仅在按键变化时发送数据包
- 支持可配置的帧间隔

### 3. UDP_Example_Top.v (修改)
- 移除数码管显示相关接口和代码
- 集成按键控制和UDP发送功能
- 保持原有的LED状态显示

## 网络配置

### 发送端（控制端）
- **IP地址**: 192.168.240.2
- **UDP端口**: 2
- **MAC地址**: 01:23:45:67:89:AB

### 接收端（被控端）
- **IP地址**: 192.168.240.1  
- **UDP端口**: 1

## 使用方法

### 控制端操作
1. **系统复位**: 按下K1键
2. **发送控制**: 按下K2键发送数字递增指令
3. **状态观察**: 通过LED观察系统状态

### 被控端要求
接收端需要实现UDP数据包解析功能：
```verilog
// 伪代码示例
if (received_data[0:1] == 0xF0AA && 
    received_data[2:3] == 0x5555 && 
    received_data[4:5] == 0x1234) {
    digit_to_display = received_data[8]; // 提取数字值
    // 控制数码管显示该数字
}
```

## 引脚分配
- **KEY1**: A2 (系统复位)
- **KEY2**: B2 (发送控制指令)
- **LED[3:0]**: B12, C10, A3, A4 (状态指示)
- **以太网接口**: 保持原有分配

## 调试功能
- **LED显示**: 接收到的网络数据状态
- **DLED[15:0]**: 用于调试显示内部状态

## 测试验证
1. **网络连通性**: 使用ping测试两端IP连通性
2. **UDP发送**: 按K2键观察网络流量
3. **数据格式**: 使用Wireshark抓包验证数据格式
4. **远程控制**: 在被控端验证数码管显示

## 注意事项
1. **网络配置**: 确保两端在同一网段 (192.168.240.x)
2. **防抖处理**: 按键已集成20ms防抖，避免重复触发
3. **发送间隔**: 每次按键变化只发送一个数据包
4. **时钟域**: 按键检测使用25MHz，UDP发送使用125MHz
5. **复位顺序**: 先复位控制端，再复位被控端
